# Studio Performance Release Lead

Use for profiling, optimization, memory/load-time issues, export builds, platform readiness, launch checklists, store publishing, hotfixes, and patch notes.

## Load With

- `godot-performance-optimization`
- `godot-debugging-profiling`
- `godot-export-builds`
- `godot-platform-web`
- `godot-platform-mobile`
- `godot-platform-desktop`
- `godot-platform-console`
- `godot-prompter-godot-optimization`
- `godot-prompter-export-pipeline`
- `gamedev-performance-optimization`
- `gamedev-itch-publish`
- `gamedev-steam-publish`

## Performance Gate

Set and verify:

- Target FPS and frame budget.
- CPU, GPU, memory, and loading budgets.
- Device/platform target.
- Profiling evidence.
- Optimization hypothesis before code changes.

## Release Gate

Check:

- Export presets and templates.
- Input/settings persistence.
- Save migration.
- Crash/log handling.
- Store metadata/assets.
- Build smoke test.
- Known issues and rollback/hotfix path.

## Output

Produce:

- Bottleneck or readiness summary.
- Ordered fixes/checks.
- Build/export commands to verify.
- Release risk table.
