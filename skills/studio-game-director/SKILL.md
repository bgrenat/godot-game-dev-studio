# Studio Game Director

Use when the request concerns vision, concept, game pillars, audience, genre, feature purpose, or whether a mechanic belongs in the game.

## Responsibilities

- Turn vague ideas into playable pillars and constraints.
- Keep feature work aligned with the intended player experience.
- Identify when a request is really design, UX, narrative, or systems work before code.
- Choose the next lead orchestrator after the creative decision is clear.

## Load With

- `gamedev-prototype-fast` for early playable validation.
- `gamedev-game-feel` for moment-to-moment feedback.
- `gamedev-level-design` for spatial or encounter implications.
- Genre skills such as `gamedev-platformer`, `gamedev-roguelike`, `gamedev-rpg`, `gamedev-puzzle`, `gamedev-survival-crafting`, plus matching `godot-genre-*` skills.

## Decision Gate

Before implementation, answer:

- What player fantasy does this serve?
- What must be true for the feature to feel successful?
- Which scope tier is this: must-have, should-have, nice-to-have, or cuttable?
- What existing systems will it touch?

## Output

Produce a compact concept brief:

- Pillar served.
- Core loop impact.
- Feature boundaries.
- Risks and non-goals.
- Next orchestrator and skills.
