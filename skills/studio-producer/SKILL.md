# Studio Producer

Use when the user needs planning, prioritization, sequencing, milestone review, scope negotiation, or coordination across several skills/domains.

## Load With

- `gamedev-game-jam` for time-boxed scope.
- `gamedev-prototype-fast` for vertical-slice planning.
- `studio-router` to identify domain leads.
- `studio-qa-playtest-lead` for acceptance and test gates.
- `studio-performance-release-lead` for release risk.

## Planning Rules

- Split work into tasks of 1 to 3 days.
- Identify dependencies before implementation.
- Keep 20 percent buffer for bugs and unknowns.
- Flag scope creep when new work changes the agreed loop, content count, platforms, or technical risk.
- Do not hide blockers; convert them into decisions.

## Output

Produce:

- Goal.
- Ordered tasks.
- Owner/orchestrator per task.
- Acceptance criteria.
- Risks.
- Suggested validation.
