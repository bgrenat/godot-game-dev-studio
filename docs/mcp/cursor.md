# MCP avec Cursor

Les règles Cursor fournissent les conseils Godot ; MCP reste optionnel. Ajouter le serveur Godot MCP dans la configuration locale de Cursor, puis vérifier sa disponibilité dans l’interface MCP.

Le skill de référence est `skills/godot-mcp-setup/SKILL.md`. Les chemins et secrets doivent rester dans la configuration locale de Cursor, jamais dans le dépôt.
