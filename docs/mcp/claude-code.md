# MCP avec Claude Code

Les skills fonctionnent sans MCP. MCP est seulement nécessaire pour automatiser des opérations dans Godot, comme lancer l’éditeur ou manipuler des scènes.

Installer le serveur Godot MCP choisi, le déclarer dans la configuration MCP de Claude Code, puis vérifier que les outils `mcp_godot_*` sont visibles. Lire `skills/godot-mcp-setup/SKILL.md` avant toute automatisation.

Ne jamais placer de secret ou de chemin personnel dans le dépôt.
