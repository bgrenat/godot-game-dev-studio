# Gemini instructions

This repository provides Godot Game Dev Studio, a curated Godot 4.7+ skill library assembled by Powehi.

For Godot/game-development tasks:

- Start with [SKILL_CATALOG.md](SKILL_CATALOG.md) or [skills_index.json](skills_index.json).
- Pick the smallest relevant skill or skill family.
- Read the selected `skills/<name>/SKILL.md` before answering.
- For broad planning, use `studio-router` or `godot-master`.
- For implementation details, use the narrow specialist skill.
- Keep answers grounded in Godot 4.7+ and GDScript best practices.
- Preserve [NOTICE.md](NOTICE.md) and license attribution.

Avoid loading all 189 skills at once.
