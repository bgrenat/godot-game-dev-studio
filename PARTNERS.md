# Partners, Credits, and Support

**Godot Game Dev Studio** is assembled and curated by **[Powehi](https://powehi.eu)**.

The plugin exists because multiple open resources were brought together into a Codex-ready package. Please preserve these credits when redistributing or adapting the project.

## Primary credits

- **Powehi** — Codex plugin assembly, packaging, curation, icon, repository publication, and ongoing distribution.
- **Divergent AI** — original GD Agentic Skills project and many of the underlying Godot agentic skill resources.
- **gamedev-skills / awesome-gamedev-agent-skills** — source/inspiration for the `gamedev-*` skill family.
- **jame581 / GodotPrompter** — source/inspiration for the `godot-prompter-*` skill family.
- **Donchitos / Claude-Code-Game-Studios** — inspiration for the Codex-adapted `studio-*` orchestration skills.
- **don-tnowe / godot-worldmap-builder** — bundled reference addon/sample under `assets/godot-worldmap-builder/`.
- **Open Godot/game-development contributors** — selected supporting examples and reference material included with their own notices.
